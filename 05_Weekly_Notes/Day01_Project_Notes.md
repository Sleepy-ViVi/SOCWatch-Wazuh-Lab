## 1. Project Objective

The objective of this project is to build a small Security Operations Centre (SOC) monitoring lab using Wazuh on AWS.

The lab will collect endpoint logs, display security alerts, test file integrity monitoring, review vulnerability findings and support basic security analysis.

## 2. Final Lab Components

The planned lab consists of:

- One Wazuh Manager
- One Wazuh Indexer
- One Wazuh Dashboard
- One Ubuntu Linux agent
- One Rocky/RHEL Linux agent
- One Windows Server agent
- AWS EC2 infrastructure
- AWS VPC and subnet
- AWS security group

## 3. Required Detection Use Cases

- Log ingestion
- File Integrity Monitoring
- Vulnerability detection
- Authentication failure detection

## 4. Core Workflow

1. Provision AWS lab
2. Install Wazuh
3. Enrol agents
4. Trigger security events
5. Analyse alerts
6. Capture evidence
